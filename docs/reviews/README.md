# Source-check reports

One file per draft investigation record. Each report checks the record's
fields and statements against the sources the record cites, and lists what
matches (with where it is in the source), what was corrected, and what is
still open.

**A report is not verification.** These checks were done by an AI assistant
(`llm:claude-opus-5-5`) at the request of Member 2, the records' author. A
record becomes `stable` only when a person other than its author reads the
record against its sources, using the report as a starting point, and adds
their own `verified:` entry (`docs/data-contract.md`). Until then every record
here stays `status: draft` and is not searched or summarised by IGNIS.

Validation is structural; these reports are the content check. Neither
replaces the reviewer's judgement.
